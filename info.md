# Home Health Overview

Home Health Overview creates health sensors for Home Assistant:

- Health Score
- offline/unknown entities
- low and critical batteries
- stale entities without updates
- temperature median, average, and outliers
- API/watchlist availability
- Sidebar panel with actionable issue lists

Install as a HACS custom repository:

```text
https://github.com/SebasJPS/HA_Overview
```

Repository type:

```text
Integration
```

After installation, restart Home Assistant and add the integration under:

Settings -> Devices & services -> Add integration -> Home Health Overview
